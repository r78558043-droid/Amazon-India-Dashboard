                                                   Amazon India Sales Dashboard

The Amazon India Sales Dashboard is a data‑analytics project built using Microsoft Excel. It transforms raw Amazon India sales data into meaningful business insights through Pivot Tables, charts, and interactive visualizations. The dashboard highlights key performance metrics such as sales trends, profit analysis, category performance, payment behavior, and order outcomes.
This project is designed to help understand customer behavior, product demand, and operational efficiency using clean, structured data visualization.

Features
1. Monthly Sales & Profit Trend
Shows how sales and profit change over time using grouped Month‑Year data.
2. Category‑wise Performance

Breakdown of:
Units Sold
Total Sales
Profit
Return & Cancellation counts
Return Rate % and Cancellation Rate %

4. Sales by Payment Method
Analysis of revenue generated through:
UPI
COD
Net Banking
Credit/Debit Cards
Wallets

4. Order Status Insights
Pivot‑based breakdown of:
Delivered Orders
Returned Orders
Cancelled Orders

5. Return & Cancellation Rates
Calculated fields inside the Pivot Table:
Return Rate % = Returned Orders / Total Orders × 100
Cancellation Rate % = Cancelled Orders / Total Orders × 100

6. Interactive Excel Dashboard
Includes slicers and dynamic charts for:
Category
Payment Method
Order Status
Month‑Year

Dataset Overview
The dataset includes:

  Order ID

  Order Date

  Category

  Quantity

  Total Sales

  Profit

  Payment Method

  Order Status (Delivered, Returned, Cancelled)

The data was cleaned and transformed to support:
 
Time‑series analysis

Category segmentation

Payment behavior analysis

Operational performance metrics

Key Insights
UPI and COD are the most used payment methods
Some categories have high sales but low profit margins
Return and cancellation rates vary significantly by category
Monthly trends reveal seasonal spikes in sales
Profit does not always correlate with units sold
